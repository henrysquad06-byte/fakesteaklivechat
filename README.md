# Steak - Steal a Brainrot (SAB) Chat Simulator 🎮

An interactive log and playback simulator for the legendary 30-minute window of Steak's "Steal a Brainrot" stream featuring 10k concurrent viewers, the great Strawberry Elephant heist, and chat shenanigans.

## 📂 Repository Contents
* `index.html` - Minimal web interface to watch the chat scroll in real-time.
* `chat_log.json` - Complete structured dataset of the chat simulation.
* `analytics.md` - Stream insights, mod logs, and community highlights.

## 🛠️ Quick Start
1. Clone the repository: `git clone https://github.com`
2. Open `index.html` in any browser to launch the live playback simulation.
